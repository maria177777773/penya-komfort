# Дело ООО «Комфорт» против Варламовой М. В. (пеня)

ООО «Комфорт» (управляющая компания посёлка) подало в Ступинский городской суд иск о неустойке 1 005 000,75 руб. за три года при долге около 100 тыс. руб. Иск датирован 28.09.2026, дело 2-8546-2026.

Позиция Маши: Комфорт сам скрывал пеню (ежемесячные квитанции и приложение показывали «Пени 0,00», на запрос остатка 10.04.2026 тоже 0,00). Пеню Комфорт начислил только после претензий и отказа Маши от договора.

Параллельно: судебные приказы 2-2384/2025 и 2-1403/2026 (по ним 09.11.2026 поданы возражения), жалобы в РПН и Минчистоты МО.

Полная таблица файлов с датами: [Материалы дела/ОПИСЬ.md](%D0%9C%D0%B0%D1%82%D0%B5%D1%80%D0%B8%D0%B0%D0%BB%D1%8B%20%D0%B4%D0%B5%D0%BB%D0%B0/%D0%9E%D0%9F%D0%98%D0%A1%D0%AC.md). Хронология: [ХРОНОЛОГИЯ.pdf](%D0%9C%D0%B0%D1%82%D0%B5%D1%80%D0%B8%D0%B0%D0%BB%D1%8B%20%D0%B4%D0%B5%D0%BB%D0%B0/%D0%A5%D0%A0%D0%9E%D0%9D%D0%9E%D0%9B%D0%9E%D0%93%D0%98%D0%AF.pdf).
